<h1 align="center">A Full-Stack Chat App using WebSockets with Auth</h1>

## 🧪 .env Setup

### Change .env.example to .env

```bash
PORT=3000
MONGO_URI=Your_MongoDB_URI
JWT_SECRET=Your_JWT_SECRET
NODE_ENV=development

```

---

## 🔧 Run the Backend

```bash
cd backend
npm install
npm run dev
```

---

## 💻 Run the Frontend

```bash
cd frontend
npm install
npm run dev
```
